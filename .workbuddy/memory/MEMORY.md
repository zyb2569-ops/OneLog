## 项目定位速记
单人自用、100% 本地离线、数据自持的 Android APK（Capacitor 8 包壳）。把物资/饮食/运动/穿搭四类记录统一进同一本地数据模型（Dexie/IndexedDB），统计层回答"该买啥/吃得怎样/练得怎样"。AI 仅用于训练域（DeepSeek，可配 baseURL），手动触发。
