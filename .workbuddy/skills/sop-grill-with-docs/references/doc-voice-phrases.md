# doc-voice-phrases

PRD 文风 pass 用的典型套话表（Tier 1 默认删或改；Tier 2 同段聚集再处理）。与 [doc-voice-structures.md](doc-voice-structures.md) 配合使用。

## Tier 1 — 默认删或改

### 开场 / 收束

| 避免 | 改法 |
|------|------|
| 值得注意的是、需要指出的是 | 删掉，直接写事实 |
| 综上所述、归根结底、总的来说、最终来看 | 删掉整句（多为空总结） |
| 希望这对你有帮助、如需我可以、请告诉我 | 删掉（chatbot 痕迹） |

### 二元 / 拔高

| 避免 | 改法 |
|------|------|
| 不是 X，而是 Y / 不仅 X，更是 Y | 直接写 Y |
| 这不仅仅是…，而是… / 这标志着…关键时刻 | 写具体事件或决策 |

### 无源权威

| 避免 | 改法 |
|------|------|
| 研究表明、数据显示、专家认为（无出处） | 删论断，或改为「（待补来源）」并保留原结构仅当用户明确要求 |
| 行业普遍认为 | 删，或写具体谁在哪年说了什么 |

### 商业 / 表演腔（中文）

| 避免 | 改法 |
|------|------|
| 赋能、抓手、闭环、对齐（作黑话）、沉淀（作黑话） | 写具体动作：上线、写入、同步、归档 |
| 落地、收口、兜住、打穿、拉满、命中（非测试语境） | 交付、完成、捕获、覆盖、跑通、匹配 |
| 极其重要、至关重要、深入探讨 | 删修饰，或换可核对事实 |

### 协作 / 元评论（英文 PRD 同样适用）

| 避免 | 改法 |
|------|------|
| Great question、It's worth noting、At the end of the day | 删掉 |
| leverage、utilize、delve into、landscape（抽象） | use、use、 examine / 直说领域 |

## Tier 2 — 同段 2+ 再减

- 此外、然而、因此、同时（连接词扎堆）
- 重要、关键、核心、显著（渲染词扎堆）
- 此外 / Furthermore 开头的连续段落

保留最贴切的一个，其余删掉或并入前句。

## Tier 3 — 仅全文密度过高

- 提升、优化、增强、改善（动词重复）
- significant、robust、effective（英文渲染词）

不机械全删；去掉重复即可。

## Protected — 不要因去味而改坏

- 已拍板的模块名、接口名、错误码
- ADR 里引用的标准术语（幂等、死锁、back-pressure 等——读者需要精确名）
- 验收项里的可观察条件
- 用户原话
