# doc-voice-structures

PRD 常见的结构级 AI tell。pass 时结构**可以**为 decompress 而变（拆句、真列表、加小标题），但不得改 protected spans 的含义。

## 1. 压缩标点

**问题**：一句塞多件事，用标点代替断句。

| 模式 | 处理 |
|------|------|
| 句中 `：` 引出长解释 | 拆成两句；或升格为列表 / 小标题 |
| 三个以上 `、` 并列（非真列举名） | 改成 `-` 列表或拆句 |
| `——` / `—` 连接两个完整分句 | 拆成两句，或留必要的那一个 |

**不要**只把顿号换成逗号——形状还在，tell 还在。

## 2. 三段式 / 排比

- 「A、B 和 C」其中 C 是凑的 → 改两项或四项，别硬凑三
- 「创新、效率、体验」类空形容词排比 → 删或换具体指标
- 段末三个平行短句 punchline → 删或留一句

## 3. 公式段落

| 模式 | 处理 |
|------|------|
| 挑战与展望：「尽管…面临挑战…未来…」 | 写具体风险或具体下一步 |
| 假对立段：「Not because X. Because Y.」 | 只留 Y |
| 段末单行金句 | 删（信息已在段内则整句删） |

## 4. 标题

标题**命名内容**，不 narrate 阅读路径。

| 避免 | 改法 |
|------|------|
| 深入探讨 X / 理解 Y 的重要性 | X / Y 是什么 |
| 接下来我们将… | （删掉这类标题，用内容小节名） |

## 5. 模糊归因

「业界认为」「多个来源表明」且无引用 → 删或补具体来源（无来源则删论断）。

## 6. 节奏过匀

连续多句长度、结构相同 → 合并两句或拆一处过满句。PRD 不需要「金句节奏」。

## 7. 中文 coaching 式第二人称

整段「你可以…你需要…你应该…」→ 改陈述：「调用方…」「系统…」「配置…」。

保留：真对比（「你的租户 id vs 平台默认租户」）。

## 自检四指标（可选）

改写前后可粗数，趋向 0：

1. staged reversal（「不是…而是…」）
2. 破折号 `——` / `—`（分句用途）
3. 句中 `、` 串三个以上并列（非专有名词列表）
4. 句中 `：` 引长解释

数字不是门槛；保真回读才是硬门槛。
