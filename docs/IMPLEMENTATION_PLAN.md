## 0. 拆分的三个前提（不满足就无法并行）

这三条是并行能不能成立的地基。任何一条没做到，项目会退化成全串行。

| 编号 | 前提 | 后果 |
|---|---|---|
| P1 | **Dexie schema v1 一次性冻结**（§6.2 全部 18 张表 + §6.3 全部索引），后续只做 `version(n+1)` 迁移，不允许"边写边加表" | 加表就触发迁移，所有并行流都要跟着改，等于全停 |
| P2 | **`stock_logs` 只能经 T05 的账本 API 写入**，域代码禁止直接 `db.stockLogs.add()` | 物资域与饮食域同时写同一张账本，冲销逻辑会各写一套，账目必然漂移 |
| P3 | **`settings` 表只能经 T02 的 settings API 读写**，各域只读自己那段字段 | 五个域同改一行，`updatedAt` 互相踩 |

## 1. 任务清单

### W0 · 决策门

| ID | 任务 | 依赖 | 产出 | 规模 |
|---|---|---|---|---|
| **T00** | **M-1 技术验证 spike**（PRD §10） | — | 三条结论 + O7 路径决策 | 0.5–1 天 |

T00 内部本身可并行（三件事互不相干，同一台机器上顺序做完即可）：
1. `capacitor.config` 开 `CapacitorHttp`，打一次真实 DeepSeek 请求 → 通/不通（A8、NET-1、R13）
2. manifest 声明 `USE_EXACT_ALARM`，锁屏 90 秒通知 → 准时 + 有声/不响（A9、R14）
3. 装 ML Kit 插件空壳，`./gradlew assembleRelease` 量体积 → 决定 O7 走 ①patch ②自写 ③接受（A6、R10）

> **硬门**：三条任一不过，禁止进 T01。这是 PRD 明确写的，不要"先写业务代码再说"。

## 2. 关键路径

```
T00 → T01 → T02 → T05 → T08(饮食) → T14(统计) → T17(AI分析) → T20(验收)
                       └→ T07(物资) ─┘
              T02 → T10(运动) → T11(计时) ─┘
```

最长链约 **18–22 人日**；其余流（T09、T12/T13、T03、T04）都有 1–3 天余量，是缓冲池。

**瓶颈在 W1，不在 W2。** W1 的 6 个任务是纯串行地基，占掉约 9–12 人日；一旦 T02 完成，才有 4 条互不干扰的流。

## 3. 并行规则（做并行时必须遵守）

| 编号 | 规则 |
|---|---|
| C1 | 一条流只改自己的目录：`src/domain/{inventory,diet,workout,stats,ai}/`。跨域改动必须经对应流的所有者 |
| C2 | 共用层（`src/db/`、`src/ui/`、`src/native/`）分别归 T02 / T04 / T03；其他流只调用不修改 |
| C3 | 每条流结束必须过 T06 的测试 + 一个集成检查点（能跑通该域的完整场景），否则不合并 |
| C4 | 同一时刻最多 2 条流。第 3 条流带来的是冲突解决成本，不是进度 |
| C5 | 数据迁移只由 T02 的所有者发起，域开发期间不允许改 schema |

| 项 | PRD 排期 | 建议 | 理由 |

## 6. 本期范围收缩（2026-10-26）

运动域与 AI 全部内容不进本期。撤出的任务：

| ID | 任务 | 连带内容 |
|---|---|---|
| T10 | 运动域 | 动作库、模板三表、逐组录入、RPE、感受标签、逐次计数 |
| T11 | 组间歇计时器 | 通知通道、`USE_EXACT_ALARM`、音频文件 |
| T15 | AI 网络与密钥层 | `CapacitorHttp`、Keystore |
| T16 | AI 计划生成 → 模板 | — |
| T17 | AI 训练分析 | `workouts.aiAnalysis` 缓存 |

**收缩后有三个连带后果，不是简单划掉五个任务：**

1. **决策门从三条验证降为一条。** M-1 里「CapacitorHttp 通 DeepSeek」服务 AI，「锁屏 90 秒精确通知」服务计时器，两条都随任务撤出。T00 只剩 ML Kit 体积实测，0.5 天。
2. **T03 少一半。** 通知通道与 `beep.wav` 移出，只剩安全区、键盘避让、权限引导。
3. **schema v1 不预留运动域的表。** 组块与超级组的结构依赖交互细节，未定形状就冻结，等于把猜测定性进迁移路径。运动域开工时走 `version(2)`。

**新的关键路径**：T00 → T01 → T02 → T05 → T08 → T14 → T18 → T20，约 15–18 人日（原 22）。原关键路径上的 T17 撤出，T16 的空位由 T14 与 T18 直接衔接。

**并行结构不变**：T02 / T03 / T04 三路；T07 与 T08 两路；T12 可与任何 W2 流并行。
